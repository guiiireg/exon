# Exon

J'utilise beaucoup YouTube pour voir mon contenu, mais je fais beaucoup de choses, donc c'est assez énervant. Il va être temps de corriger cela.

Ce que j'espère c'est que les personnes voyant ce site puissent me découvrir, ou alors trouver **tout** mon contenu.

## Construit avec

* HTML5 - Sémantique obligatoire pour un site accessible à tout le monde.
* CSS3 - Des animations classiques pour rendre un site propre visuellement.

## Roadmap

Je pense que ce site web va passer d'un site vitrine basique à une vraie application complète sur toutes les plateformes.

Voilà l'ordre dans lequel l'ordre est pensé :

* Faire le site HTML5 avec toutes les informations et pages.
* Faire le CSS3 basique pour toutes les animations et visuels basiques.
* Faire le JavaScript pour des animations plus complexes et de l'interactivité.
* Passe à un framework front-end (React / Angular).
* Réaliser le back-end en natif.
* Modifier le back-end pour passer sur un framework.
* Créer une application mobile avec flutter.

## Statut du projet

Ce projet est au début et en cours, mais il n'est clairement pas abandonné ou en pause, loin de là.

## Contribuer

Pour contribuer à Exon, vous devez cloner ce repository GitHub, et ensuite faire vos modifications dans la branche que vous faites.

Une autre façon de contribuer est d'ouvrir une issue pour faire remarquer un problème.

Cependant, il y a des règles à respecter :
* Toujours faire des tests unitaires (si sur le back-end).
* Interdiction de l'IA pour coder.
* Basez-vous sur les schémas pour l'architecture et la conception des données.
* Faites des commits atomiques (petits commits par commits, pas de commit de milliers de lignes).
* Une fois la fonctionnalité terminée, vous pouvez faire la PR sur votre branche.
